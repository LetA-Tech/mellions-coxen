# Arming a fix aimed at a model

Part of `mellions-falsification`, read when the fix is an instruction or a refusal a model receives.

Where the fix is an instruction or a refusal aimed at a model — a Skill, a
prompt, a hook — run the arm without the edit too: the model does much of the
intended work unprompted, and one treated run credits the change with the
model's own competence. The case both arms run must be one the untreated arm
can fail, so neither state the conclusion the change exists to produce nor
hand the offending command cold, which an unpressured model declines on its
own; build it from the conditions the change will meet — the reason accepted,
the objections answered, the work under way — unless being handed it cold is
the condition, and then the untreated arm still has to be shown failing. A
null is a fact about the case, not the change. Decide what counts as a
difference before reading either arm; the claim is only what the difference
shows.

An arm is blind only with no route to the hypothesis, the criterion or which
arm it is; for a treated arm the edit as it will ship is the treatment, not a
route — its diff, history and messages are — and for an untreated arm the edit
is one. A route can run through its brief and what loads with it — a forked
conversation, `CLAUDE.md`, memory, hooks, skills, its directory's path and git
state; the lane by path, transcript or any `mellions` command; an issue, pull
request, branch or commit stating any of them; another arm's files or
processes; a name that marks which arm it is. No arm that can read the host's
files or run a command there is blind, whatever its directory or worktree: a
subagent's tools reach its parent's disk and credentials. Any other arm — a
session with no tools, a container — is blind only if nothing it holds, mounts
or can fetch when it runs is a route. Before any arm starts, record the
criterion and how each arm is built; brief none with anything of the lane,
rebuilding the conditions rather than copying them, and hand a treated arm the
edit as a copy; house each arm apart, outside the lane and its scratch, with
its full log kept past teardown and, where its housing allows, out of its
reach. Label each arm in the proof: blind by construction where its recorded
build gave it no route; otherwise, from its build and its log and not its own
account, reachable but unread, or unblinded once anything it loaded, received
or read carried a route; an arm not blind by construction with no log is
unverified, counted as unblinded. Read a difference only between arms with the
same label, never between unblinded ones.
