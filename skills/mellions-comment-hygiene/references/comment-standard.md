# Comment Determination

Determine which of the five categories a thing belongs to, then apply the matching
rule in `SKILL.md`.

| Category | Covers | Examples | Treatment |
| --- | --- | --- | --- |
| Ordinary comment | Current behavior, invariants, constraints, contracts, non-obvious reasoning. Line, block, inline, and test-explanation forms. | `// Explain the invariant.`<br>`/* Explain the constraint. */`<br>`retry() // Retry only transient errors.`<br>`// Use a fixed clock to make expiry deterministic.` | Keep only when current, necessary, verified, non-obvious, and three lines or fewer. |
| Documentation comment | Current exported API or symbol contract. | `// Done returns a channel that closes when the consumer has drained.` | Ordinary-comment rules apply, including the three-line limit unless the documentation tooling requires another format. |
| Machine-readable annotation | Build tags, compiler directives, OpenAPI annotations, linter directives, generator instructions. | `//go:build integration`<br>`//go:generate mockgen ...`<br>`// @Router /api/v1/messages [post]`<br>`//nolint:gosec // Reason.` | Not an ordinary comment. Identify the consuming tool, preserve required syntax, update when behavior changes, remove only when verified obsolete. |
| Special standardized comment | Generated-code markers and approved legal headers. | `// Code generated by mockgen. DO NOT EDIT.`<br>Copyright block at the top of a file | Preserve. Fix a generated marker at the generator, never by hand. A legal header changes only when the legal standard changes. |
| Prohibited comment | Agent logs, implementation history, issue and remediation narratives, slate entries, temporary plans, speculation, obvious narration, commented-out code. | `// Added for FSOR-BUG-021.`<br>`// TODO: remove this later.`<br>`// legacyResolver.Resolve(...)`<br>`// Increment the retry count.` | Delete. Being a comment does not make removal optional. Rewrite only if a verified current constraint remains once the prohibited content is stripped. |

Native language metadata — annotations, decorators, struct tags, attributes — is not
a comment and is outside this classification entirely.
